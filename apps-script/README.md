# 하객 사진/영상 업로드 백엔드 설정

청첩장 하단의 '사진·영상 올리기' 버튼은 **본인 구글 계정의 Apps Script 웹 앱**을 통해
하객의 사진·영상을 구글 드라이브 폴더에 **원본 그대로** 저장합니다. (압축 없음, 이어올리기 지원)

`config.js`의 `interact.endpoint`가 비어 있으면 버튼을 눌러도 "준비 중" 안내만 나오고 아무것도 전송되지 않습니다.

## 1. 폴더 만들기

1. 구글 드라이브에서 사진을 받을 **폴더**를 만듭니다. (이름 예: `하객 사진`)
   - 주소 `https://drive.google.com/drive/folders/【여기】`의 【여기】가 `FOLDER_ID`입니다.

## 2. Apps Script 프로젝트 만들기

1. <https://script.google.com>에서 **새 프로젝트**를 만듭니다.
2. 기본 `Code.gs` 내용을 지우고, 이 폴더의 `Code.gs`를 통째로 붙여 넣습니다.
3. 왼쪽 ⚙️ **프로젝트 설정**에서 **"편집기에서 appsscript.json 매니페스트 파일 표시"**를 켭니다.
   그런 다음 `appsscript.json` 내용을 이 폴더의 파일로 바꿉니다.
4. 같은 설정 화면 아래 **스크립트 속성**에 다음 값을 추가합니다.

| 속성 | 값 | 필수 |
|---|---|---|
| `FOLDER_ID` | 1번에서 확인한 폴더 ID | ✅ |
| `ALLOWED_ORIGINS` | `https://yjw5344.github.io` (로컬 테스트 시 `,http://localhost:8000` 추가) | |
| `MAX_FILE_MB` | 파일당 최대 MB (기본 2048) | |
| `UPLOAD_FROM` / `UPLOAD_UNTIL` | 업로드 허용 기간 `YYYY-MM-DD` | |

## 3. 권한 승인

1. 편집기 위쪽 함수 목록에서 `setup`을 고르고 **실행**을 누릅니다.
2. "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동 → 허용**을 누릅니다.
   - 본인 계정으로 본인 스크립트를 승인하는 것이므로 안전합니다. 하객에게는 이 화면이 나오지 않습니다.
3. 실행 로그에 `폴더 OK`가 찍히는지 확인합니다.

## 4. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**를 누르고, 유형으로 **웹 앱**을 고릅니다.
2. **실행 계정은 `나`**, **액세스 권한은 `모든 사용자`**로 설정합니다.
3. 배포를 누르면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
4. `config.js`의 `interact.endpoint`에 붙여 넣고 커밋·푸시합니다.

> 코드를 수정한 뒤에는 **배포 → 배포 관리 → ✏️ → 버전: 새 버전**으로 다시 배포해야 반영됩니다.
> 이렇게 하면 URL은 그대로 유지됩니다.

## 동작 방식

```
브라우저 ─(파일명·크기·형식)─▶ 웹 앱 ─▶ 드라이브 이어올리기 세션 생성 ─▶ uploadUrl
브라우저 ─(8MB씩 PUT)────────▶ uploadUrl ─▶ 드라이브 폴더에 원본 저장
```

- 파일 내용은 Apps Script를 거치지 않고 드라이브로 직접 갑니다. 그래서 Apps Script 요청 용량(약 50MB) 제한을 받지 않습니다.
- 브라우저가 받는 것은 **파일 1개 전용 업로드 주소**뿐입니다. 계정 토큰이나 폴더 ID는 노출되지 않습니다.
- 저장되는 파일 이름은 `20260307-131522_올린사람_원본파일명.jpg` 형식입니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "준비 중" 안내만 나옴 | `config.js`의 `interact.endpoint` 값 |
| 업로드가 `origin_not_allowed`로 실패 | `ALLOWED_ORIGINS`에 지금 접속한 주소(예: `http://localhost:8000`)가 있는지 |
| 업로드가 `upload_closed`로 실패 | `UPLOAD_FROM` / `UPLOAD_UNTIL` 기간 |
| `server_error` | Apps Script의 **실행** 메뉴에서 오류 로그 확인 (보통 속성 값 누락) |
